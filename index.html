§03 — Selected Work

Six end-to-end projects.

01.

AI Stock & Market Analysis Platform ↗

A research assistant that answers investing questions in plain English. Four specialised agents — Fundamentals, Sentiment, Macro, and Technical — split each question between them, work in parallel, and stream a buy/hold/sell view back to the user in seconds.

LangGraph · MCP · Claude · FastAPI · PostgreSQL · Redis
02.

Real-Time Shoe Personalization ↗

An end-to-end streaming pipeline built to learn how Kafka, Flink, and CrewAI fit together. Python producers simulate a shoe store — clicks, cart actions, inventory updates — Flink SQL turns those events into live user and product profiles, and a CrewAI agent reads that context to produce a recommendation in real time.

Kafka · Flink · CrewAI · ChromaDB · Docker
03.

TariffPulse — Tariff Shock Propagation ↗

An analyst tool for global trade risk. Given a tariff change, it walks four tiers of semiconductor supply-chain relationships in a knowledge graph and cross-checks the impact against SEC filings — turning a question that takes a human analyst hours into one that takes a minute.

AutoGen · LlamaIndex · Neo4j · Weaviate
04.

WikiWatch ↗

A live monitor for the Wikipedia edit stream. The system reads every edit as it happens, scores 5-minute windows for unusual activity (vandalism, bot swarms), and shows the spikes on a dashboard — the kind of system used inside trust-and-safety teams, built end-to-end.

Kafka · Flink · PyTorch · FastAPI · React
05.

AI-Powered Standup Assistant ↗

A small tool that replaces the daily standup meeting. It collects async check-ins, summarises them with GPT-4, makes them searchable, and posts a digest into Slack — so the team gets the signal without the half-hour call.

FastAPI · GPT-4 · ChromaDB · Streamlit · Slack API
06.

Job Web Portal ↗

A full-stack jobs board with the parts a real product needs: separate sign-ups for seekers and employers, role-based permissions, resume uploads, application tracking, and an admin view — all deployed on AWS.

Spring Boot 3 · MySQL · AWS · REST
